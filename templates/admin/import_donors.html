📇 Import Donor Data

Upload a CSV of donor personal details -- contact info, PAN/address, Donor Type, Connected Preacher, Donation Frequency, gifts, and family dates (birthdays, marriage anniversary). No donation records are created -- this only creates/updates Donor profiles, the same fields you'd fill in one-by-one under Admin -> Donors -> Edit.

Each row is matched to an existing donor by PAN, then phone, then email (same priority used everywhere else in the app). A match updates that donor -- a value left blank in the row leaves whatever's already on file untouched, so you can re-upload the same file, or a file with only a few columns filled in, without wiping out existing data. No match creates a new donor.

⬇ Download demo/template CSV

Required column: full_name. Everything else is optional -- see the demo file for every column, including donor_type (iyf / live_to_give), connected_preacher_name (must match an existing Preacher name from Admin -> Preachers, or use none to clear an assignment), donation_frequency (one_time / monthly / quarterly / yearly / occasional), and dates as YYYY-MM-DD.
