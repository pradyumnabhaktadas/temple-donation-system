🗂 Import Historical Donor Data

For a single old record -- same rules as the bulk uploader below (receipt number kept as-is if you have one, no PDF unless you ask for it, donor never notified), just without preparing a whole file for one row.

For migrating donor/donation history from before this website existed -- where a receipt was already issued (on paper, or through your old system). This is different from Bulk Import, which is for logging new offline donations that need a receipt generated now.

  • Put your old receipt number in the receipt_number column to keep it as the number of record. Leave it blank if you don't have one -- the donation still imports and counts correctly everywhere (totals, Analytics, Form 10BD), it just won't get a receipt number assigned. This site's own numbering sequence is never auto-generated for a legacy row, since that would misrepresent it as an official receipt this site actually issued.
  • No PDF is generated by default (the real receipt already exists elsewhere) -- tick the box below if you want a PDF in this site's own layout generated anyway. It won't look like the original, and rows with no receipt_number won't get a PDF either (there's no number to print on it).
  • Use is_80g_requested (yes / no / blank) to record whether that particular donation was 80G or not -- useful for campaigns like Live To Give where donors choose per-donation. Leave it blank to use the campaign's own default.
  • Donors are never emailed or WhatsApp'd for imported rows.
