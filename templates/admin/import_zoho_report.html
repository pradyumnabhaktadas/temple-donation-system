📥 Import Zoho Report

For donations taken through a Zoho Form where no receipt was issued. Export the form's report from Zoho (it must include the Payment Transaction ID column) and upload it here. Every row with a real payment is checked against Razorpay, and the ones Razorpay confirms as captured become donations with real receipt numbers.

Rows without a payment — cash registrations, forms someone filled in and never paid for — are skipped and counted, not treated as errors. Payments already recorded are skipped too, so re-uploading an overlapping export is safe and cannot produce a second receipt for the same payment.

One Zoho form's export at a time — every row in the file is filed under this campaign.
Off by default. A donor who gave six weeks ago usually shouldn't get a receipt that reads as though it just happened — the receipt is still issued and stored either way, and can be sent later from their record.
Preview checks the whole file and shows what would happen, row by row, without saving anything. Worth doing first: importing issues real receipt numbers and can message donors, and neither is easy to take back.
